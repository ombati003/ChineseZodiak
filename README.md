Chinese Zodiac Project

A PHP-based web application that dynamically displays the 12 signs of the Chinese Zodiac along with their respective images in an HTML table layout.

Features

Dynamic Array Rendering: Uses PHP arrays to map Chinese Zodiac signs to their image file paths.

Automated Table Generation: Utilizes PHP for loops to generate table headers and image elements dynamically.

Strict XHTML Compliance: Formatted with self-closing image tags and standard-compliant HTML tags.


Setup & Usage

Copy the project directory to your local web server root (e.g., www/ or htdocs/ in WampServer/XAMPP).

Ensure all 12 zodiac images are placed inside the /images/ directory using the standard .jpg naming convention.

Open your web browser and navigate to http://localhost/ChineseZodiac/index.php.
